# Gabs Semijoias — Catálogo

Site estático (HTML + CSS + JavaScript, sem dependências) publicado no GitHub Pages.

## Como editar as peças
Abra `index.html`, procure `const PRODUCTS = [` e edite a lista:
- `cat`: Brincos, Anéis, Colares ou Pulseiras
- `name`: nome da peça
- `price`: preço com ponto (ex.: 64.99)
- `img`: nome do arquivo da foto na raiz do repositório (sem `.jpg`)
- `size`: tamanho do anel (opcional)

Para adicionar uma peça: envie a foto para a raiz do repositório e copie uma linha da lista.
WhatsApp da loja: constante `WA` no início do script.

## Prévia do link (WhatsApp/Instagram)
A imagem da prévia está na tag `og:image` e precisa ser o endereço completo (`https://gabssemijoias.github.io/...`). Depois de trocar, o WhatsApp pode levar alguns dias para atualizar a prévia de um link já compartilhado.
